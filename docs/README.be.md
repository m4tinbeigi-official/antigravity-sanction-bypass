# 🚀 Абыход санкцый Antigravity (Vercel Relay)

Афіцыйны плагін Antigravity для хуткага і надзейнага доступу да Google Antigravity і мадэляў Gemini з краін з рэгіянальнымі абмежаваннямі (Беларусь і інш.).

---

## ✨ Асноўныя магчымасці
- **Аўтаматычнае вызначэнне рэгіёну**: пры выяўленні абмежаванага IP трафік аўтаматычна праходзіць праз глабальныя серверы Vercel Edge.
- **Няма памылак 403 / Region Not Supported**: запыты выконваюцца праз дата-цэнтры ў ЗША і Еўропе.
- **Абарона ад блакавання DNS**: прамы выхад на Anycast IP Vercel пры праблемах у правайдэра.
- **Персанальнае рэле бясплатна**: магчымасць хуткага стварэння ўласнага рэле.

---

## 🛠️ Каманды CLI (`agy-relay`)
```bash
agy-relay status          # Праверка статусу і пінгу
agy-relay set <url>       # Устаноўка новага рэле
agy-relay test            # Тэст пінгу да Gemini
agy-relay start           # Запуск сэрвісу
agy-relay restart         # Перазапуск сэрвісу
agy-relay stop            # Спыненне сэрвісу
agy-relay lang be         # Усталяванне беларускай мовы
agy-relay guide           # Інструкцыя па стварэнні рэле
```
