# 🚀 Antigravity ပိတ်ပင်မှုကျော်လွှားစနစ် (Vercel Relay)

Google Antigravity နှင့် Gemini မော်ဒယ်များကို ကန့်သတ်ဒေသများ (မြန်မာနိုင်ငံ အပါအဝင်) မှ အဆင်ပြေချောမွေ့စွာ အသုံးပြုနိုင်ရန် ပြုလုပ်ထားသော တရားဝင် Antigravity ပလပ်ဂင် ဖြစ်ပါသည်။

---

## ✨ အဓိကလုပ်ဆောင်ချက်များ
- **ဒေသအခြေအနေ အလိုအလျောက်စစ်ဆေးခြင်း**: ကန့်သတ်ခံရသော IP ဖြစ်ပါက Vercel Edge မှတစ်ဆင့် ချိတ်ဆက်ပေးသည်။
- **403 / Region Not Supported အမှားများမရှိစေခြင်း**: အမေရိကနှင့် ဥရောပရှိ ဆာဗာများမှတစ်ဆင့် ဆောင်ရွက်ပေးသည်။
- **DNS ပိတ်ဆို့မှုများအား ကျော်လွှားနိုင်ခြင်း**: တိုက်ရိုက် Vercel Anycast IP များဖြင့် ချိတ်ဆက်ပေးသည်။
- **အခမဲ့ကိုယ်ပိုင် Relay ပြုလုပ်နိုင်ခြင်း**: မိနစ်ပိုင်းအတွင်း အခမဲ့ကိုယ်ပိုင် Relay ပြုလုပ်အသုံးပြုနိုင်သည်။

---

## 🛠️ CLI ညွှန်ကြားချက်များ (`agy-relay`)
```bash
agy-relay status          # ချိတ်ဆက်မှု အခြေအနေနှင့် ကြာချိန်စစ်ဆေးရန်
agy-relay set <လင့်ခ်>   # Relay လင့်ခ်အသစ် သတ်မှတ်ရန်
agy-relay test            # Gemini နှင့် ချိတ်ဆက်မှု စမ်းသပ်ရန်
agy-relay start           # အလုပ်လုပ်ဆောင်မှု စတင်ရန်
agy-relay restart         # ပြန်လည်စတင်ရန်
agy-relay stop            # ရပ်တန့်ရန်
agy-relay lang my         # မြန်မာဘာသာသို့ ပြောင်းရန်
agy-relay guide           # ကိုယ်ပိုင် Relay ပြုလုပ်နည်း လမ်းညွှန်ကြည့်ရန်
```
