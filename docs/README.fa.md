# افزونه عبور از تحریم آنتی‌گرویتی (رله ورسل)

افزونه رسمی آنتی‌گرویتی برای دسترسی پرسرعت، پایدار و بدون قطعی به مدل‌های جمنای و کلاد کد گوگل از مناطق تحت تحریم و محدودیت‌های جغرافیایی (ایران، کوبا، سوریه، کره شمالی، روسیه، بلاروس، میانمار و...).

سازگاری ۱۰۰٪ با تمامی سیستم‌عامل‌ها و پردازنده‌ها:
- **مک (macOS)**: پردازنده‌های اپل سیلیکون (M1، M2، M3، M4) و اینتل (x86-64)
- **ویندوز (Windows)**: ویندوز ۱۰ و ۱۱ (نسخه‌های ۶۴ بیتی و ARM64)
- **لینوکس (Linux)**: اوبونتو، دبیان، آرچ، فدورا، اوپن‌سوزه

---

## نصب سریع در ۳ ثانیه (One-Click)

### مک و لینوکس
ترمینال را باز کرده و دستور زیر را اجرا کنید:
```bash
curl -fsSL https://raw.githubusercontent.com/m4tinbeigi-official/antigravity-sanction-bypass/main/install.sh | bash
```

### ویندوز (PowerShell)
پاورشل را باز کرده و دستور زیر را اجرا کنید:
```powershell
irm https://raw.githubusercontent.com/m4tinbeigi-official/antigravity-sanction-bypass/main/install.ps1 | iex
```

### نصب از طریق نودجی‌اس (تمامی سیستم‌عامل‌ها)
در صورت نصب بودن Node.js:
```bash
git clone --depth 1 https://github.com/m4tinbeigi-official/antigravity-sanction-bypass.git ~/.gemini/config/plugins/antigravity-sanction-bypass
node ~/.gemini/config/plugins/antigravity-sanction-bypass/install.js
```

## پنل تحت وب زنده و استاندارد وایب فارسی

پس از نصب، داشبورد مدیریت روی آدرس زیر در دسترس است:
**`http://127.0.0.1:19876/`**

ویژگی‌های پنل:
- **کلید روشن/خاموش آنی**: قطع و وصل کردن فوری رله بدون نیاز به دستور یا ری‌استارت آنتی‌گرویتی.
- **تست پینگ زنده**: سنجش تاخیر رفت‌وبرگشت به سرورهای جمنای با ارقام فارسی.
- **تحلیل فنی وضعیت ۴۰۳**: تشریح دلیل اینکه چرا دریافت پاسخ رسمی `HTTP 403` از گوگل اثبات ۱۰۰٪ عبور از تحریم و اتصال مستقیم به هسته جمنای است.
- **تنظیم رله اختصاصی**: تغییر و ذخیره آدرس رله با اعتبارسنجی در لحظه.
- **کنسول لاگ خام**: مشاهده لاگ هدرها و پاسخ‌های سرور.

## دستورات ترمینال (`agy-relay`)

| دستور | توضیحات |
| :--- | :--- |
| `agy-relay status` | نمایش وضعیت سرویس، کشور شناسایی‌شده و پینگ |
| `agy-relay test [url]` | تست اتصال زنده و محاسبه میلی‌ثانیه تاخیر |
| `agy-relay set <url>` | تنظیم و ذخیره رله اختصاصی ورسل |
| `agy-relay start` | شروع سرویس در پس‌زمینه روی پورت ۱۹۸۷۶ |
| `agy-relay stop` | توقف سرویس رله |
| `agy-relay restart` | راه‌اندازی مجدد سرویس |
| `agy-relay guide` | راهنمای ۱ دقیقه‌ای دپلووی رله رایگان شخصی روی ورسل |

## دپلووی رله رایگان شخصی در ۱ دقیقه

برای اجرای رله اختصاصی روی اکانت رایگان ورسل خود:
۱. وارد حساب کاربری رایگان خود در [Vercel](https://vercel.com) شوید.
۲. در ترمینال دستورات زیر را وارد کنید:
   ```bash
   cd ~/.gemini/config/plugins/antigravity-sanction-bypass/templates/vercel-relay
   npx vercel --prod --yes
   ```
۳. آدرس به دست آمده را به عنوان رله فعال ثبت کنید:
   ```bash
   agy-relay set https://your-app.vercel.app
   ```
