# 🚀 دور زدن تحریم‌های آنتی‌گرویتی (Vercel Relay)

این پلاگین رسمی آنتی‌گرویتی امکان اتصال پایدار، سریع و بدون ارور به Google Antigravity و مدل‌های هوش مصنوعی Gemini را از کشورهای تحت تحریم (نظیر ایران) به صورت خودکار فراهم می‌کند.

---

## ✨ ویژگی‌های کلیدی
- **تشخیص خودکار تحریم**: در صورت تشخیص آی‌پی کشورهای تحریم‌شده، کلیه ترافیک به صورت خودکار از طریق سرورهای Edge ورسل رله می‌شود.
- **بدون خطای ۴۰۳ یا Region Not Supported**: ترافیک از نزدیک‌ترین دیتاسنترهای آمریکا یا اروپا عبور می‌کند.
- **ضد فیلترینگ DNS**: استفاده از آی‌پی‌های Anycast مستقیم در صورت اختلال در دامنه‌های vercel.app.
- **امکان اتصال رله اختصاصی**: هر کاربری می‌تواند رله ورسل شخصی خود را با دستور `agy-relay set <url>` ثبت کند.

---

## 🛠️ دستورات خط فرمان (`agy-relay`)
```bash
agy-relay status          # مشاهده وضعیت سرویس و پینگ زنده
agy-relay set <link>      # تغییر آدرس رله ورسل
agy-relay test            # تست ارتباط با جمنای
agy-relay start           # اجرای سرویس پل پس‌زمینه
agy-relay restart         # ریستارت پل محلی
agy-relay stop            # متوقف کردن سرویس
agy-relay lang fa         # تنظیم زبان پیش‌فرض به فارسی
agy-relay guide           # راهنمای ساخت رله رایگان شخصی
```
