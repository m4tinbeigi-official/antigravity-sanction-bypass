# 🚀 تجاوز قيود جوجل أنتي غرافيتي (مرحل فيرسل)

إضافة رسمية لنظام Google Antigravity تتيح الاتصال المستقر والسريع بنماذج Gemini دون انقطاع ودون أخطاء 403 من المناطق الخاضعة للقيود الإقليمية (سوريا، السودان، وغيرها).

---

## ✨ الميزات الرئيسية
- **كشف تلقائي للمنطقة**: في حال كان عنوان IP تابعاً لمنطقة مقيدة، يتم توجيه حركة المرور تلقائياً عبر خوادم Vercel Edge.
- **تجاوز خطأ 403 / Region Not Supported**: توجيه الطلبات عبر خوادم أمريكا وأوروبا السريعة.
- **مقاومة حجب وتسميم DNS**: التبديل التلقائي إلى عناوين Anycast المباشرة لفيرسل عند وجود مشكلات في مزود الخدمة المحلي.
- **إمكانية استخدام مرحل خاص مجاني**: يمكن لكل مستخدم نشر مرحل خاص به على حسابه المجاني في Vercel وتعيينه بضغطة زر.

---

## 🛠️ أوامر سطر الأوامر (`agy-relay`)
```bash
agy-relay status          # التحقق من حالة الاتصال وزمن الاستجابة
agy-relay set <رابط>      # تعيين رابط مرحل جديد
agy-relay test            # اختبار الاتصال المباشر بجيمناي
agy-relay start           # تشغيل الخدمة في الخلفية
agy-relay restart         # إعادة تشغيل الخدمة
agy-relay stop            # إيقاف الخدمة
agy-relay lang ar         # تعيين اللغة الافتراضية إلى العربية
agy-relay guide           # عرض دليل إنشاء مرحل مجاني خاص بك
```
