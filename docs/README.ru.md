# 🚀 Обход региональных ограничений Antigravity (Vercel Relay)

Официальный плагин Antigravity для стабильного, быстрого и бесперебойного доступа к Google Antigravity и моделям Gemini из стран с региональными ограничениями (Россия, Беларусь, Крым и др.).

---

## ✨ Основные возможности
- **Автоматическое определение региона**: при обнаружении ограниченного IP-адреса трафик автоматически маршрутизируется через глобальные Vercel Edge Relays.
- **Отсутствие ошибок 403 / Region Not Supported**: запросы обслуживаются дата-центрами в США и Европе.
- **Устойчивость к DNS-блокировкам**: автоматический переход на прямые Anycast IP Vercel (`64.29.17.131`, `216.198.79.131`) при сбоях локального DNS.
- **Поддержка персонального реле**: возможность легко подключить собственное Vercel реле.

---

## 🛠️ Команды CLI (`agy-relay`)
```bash
agy-relay status          # Проверка статуса и пинга
agy-relay set <url>       # Установка нового URL реле
agy-relay test            # Тестирование пинга к Gemini
agy-relay start           # Запуск локального моста
agy-relay restart         # Перезапуск сервиса
agy-relay stop            # Остановка сервиса
agy-relay lang ru         # Установка языка интерфейса на русский
agy-relay guide           # Руководство по развертыванию личного реле
```
