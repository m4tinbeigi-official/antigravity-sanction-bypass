# 🚀 Antigravity Sanction Bypass (Vercel Relay)

An official Antigravity plugin providing seamless, zero-config, high-speed access to Google Antigravity and Gemini models from sanctioned and geo-restricted countries (Iran, Cuba, Syria, North Korea, Russia, Belarus, Myanmar, etc.).

## ✨ Key Features
- **Automatic Geo & Sanction Detection**: Detects your public IP and country code. If in a sanctioned or restricted country (`IR`, `CU`, `SY`, `KP`, `RU`, `BY`, `MM`, etc.), it automatically routes Gemini and Antigravity traffic through Vercel Edge Relays.
- **Zero 403 / Region Errors**: Replaces standard blocked requests with global edge-routed requests from US/EU datacenters.
- **Anti-DNS-Poisoning Resilience**: If your local ISP DNS poisons or throttles `*.vercel.app` domains, the built-in bridge automatically falls back to direct Anycast IPs (`64.29.17.131`, `216.198.79.131`) while preserving TLS SNI.
- **Custom Relay Support**: Comes pre-configured with a default public relay (`https://vercel-relay-71xprds6r-m4tinbeigiis-projects.vercel.app`), but allows any user to connect their own private Vercel relay with one command.
- **Interactive In-Chat Widget**: Live widget displaying latency, detected IP, status, and 1-click relay switcher in 8 languages.

## 🛠️ Command-Line Interface (`agy-relay`)

| Command | Description |
| :--- | :--- |
| `agy-relay status` | Display daemon status, detected country, sanction status, and ping to Gemini |
| `agy-relay set <url>` | Update the active Vercel relay URL and hot-reload the daemon |
| `agy-relay test [url]` | Test live connectivity and measure latency to Google Gemini |
| `agy-relay start` | Start the local bridge daemon in the background on port `19876` |
| `agy-relay stop` | Stop the background daemon |
| `agy-relay restart` | Restart the daemon |
| `agy-relay lang <code>` | Set default CLI language (`en`, `fa`, `ru`, `ar`, `es`, `ko`, `be`, `my`) |
| `agy-relay guide` | View the 1-minute personal Vercel deployment guide |

You can also pass `--lang=<code>` to any command (e.g. `agy-relay status --lang=ru`).

## ⚡ 1-Minute Personal Vercel Relay Deployment (100% Free)

To deploy your own private high-speed relay on Vercel:
1. Log into your free [Vercel](https://vercel.com) account.
2. Open terminal and run:
   ```bash
   cd ~/.gemini/config/plugins/antigravity-sanction-bypass/templates/vercel-relay
   npx vercel --prod --yes
   ```
3. Copy the URL generated by Vercel and register it in Antigravity:
   ```bash
   agy-relay set https://your-deployment.vercel.app
   ```

## ⚙️ Architecture & Local Endpoints
- **Local Reverse Proxy**: `http://127.0.0.1:19876`
  - Gemini API route: `http://127.0.0.1:19876/gemini/*`
  - Cloud Code route: `http://127.0.0.1:19876/cloudcode/*`
  - Health & Status: `http://127.0.0.1:19876/status`
- **Configuration File**: `~/.gemini/antigravity/sanction-relay-config.json`
